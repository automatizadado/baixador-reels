# Baixador de Reels

Aplicação web simples e otimizada para celular.

## O que faz
- Recebe a URL ou @ de um perfil público do Instagram
- Permite escolher 10, 25 ou 50 vídeos
- Baixa os vídeos encontrados
- Entrega tudo em um arquivo ZIP

## Hospedagem
O projeto inclui `render.yaml` para facilitar a implantação em um serviço Python compatível com Render.

## Importante
O Instagram pode limitar ou bloquear consultas automatizadas, portanto o funcionamento sem autenticação não é garantido permanentemente. O aplicativo não contorna login, perfil privado ou controles de acesso.

Use apenas conteúdo que você tenha direito ou permissão para baixar e reutilizar.
